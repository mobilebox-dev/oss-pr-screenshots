# Screenshots from PR test runs

Screenshots from running open-source Android pull requests on cloud phones, one folder per app. They are embedded in PR comments that link back here. Nothing else lives here.

The runs used [Mobilebox](https://mobilebox.dev), cloud phones for testing apps, which we build. Each app stays with its own license and authors; these are unedited screenshots of their apps.

Want a screenshot removed? Open an issue or mention @Musti7even and it's gone.
